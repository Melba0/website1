# 一枝桂赏月宴

一次「真的走进饭店」的沉浸式体验：**到店 → 看天时 → 推门 → 迎宾 → 大堂 → 走廊 → 包间 → 落座 → 点菜调口味 → 上菜 → 生成月宴图**。

不是一上来就罗列所有选项：**天时在门口一问一答地选，包间在走廊里一间一间走过，口味落座后才调，每道菜的微调是主角。**

---

## 一、怎么跑起来（本地部署）

```powershell
node server.mjs 8787
```

浏览器打开 **http://127.0.0.1:8787/**

> 也可直接双击 `index.html`（纯静态、无依赖、无构建、不联网）；但 ES 模块在 `file://` 下会被浏览器拦截，用本地服务器更稳。

环境：任何现代浏览器。服务器只用 Node 内置模块，无 npm 依赖。

## 二、动线与人机对应

| 步 | 场景 | 你做什么 | 系统做什么 |
|---|---|---|---|
| 零 | **门庭** | 鼠标轻移，按「拾级而上」 | 一枝桂自右上横斜掠过月前，花瓣飘落；月亮随鼠标微移；荷叶缸月影起涟漪；檐下灯笼轻晃；古琴声起 |
| 一 | **门口选天时** | **其一：抬头点天** 选天气；**其二：低头拖灯笼** 定更次 | 月亮位置、云气、雨霜、光色、音景、匾下诗句实时改变；**月亮可直接拖动** |
| 二 | **大堂** | 听小二按天时迎宾，看水牌 | 依「天气 × 时刻」生成迎宾语与水牌 |
| 三 | **走廊长卷** | **左右拖动**走过六间；走近门自动半开；**探头**预览；**入此间** | 六扇门各有门牌、竖联、宫灯、灯柱、门槛石；探过的门牌亮起；尽头小二「请小二推荐」 |
| 四 | **包间落座（三幕）** | 壹落座：定口味、报忌口、说心愿　贰上菜：拖拽排次第、**逐道看微调**　叁佐宴：换茶饮小菜盘器诗签 | 茶饮/小菜/盘器/诗句**自动相配**；席面四项评分；诗人客、老饕客、孩童客、远方客各有反应 |
| 五 | **成宴** | 圆桌六盘可点开配方；抄宴帖、存宴图、再走一遍、全局随缘 | 生成「包间·天气时刻·心愿宴」赏月宴图与月光卡 |

### 随机按钮（每种都按场景命名）

| 变量 | 按钮 | 位置 |
|---|---|---|
| 天气 | **风起随缘** | 天空右下角 |
| 时刻 | **听更** | 灯笼旁 |
| 包间 | **请小二推荐** | 走廊尽头 / 大堂 |
| 上菜次第 | **先生定序** / **随缘排序** | 贰上菜 |
| 茶饮 · 小菜 | **换一换** | 叁佐宴 |
| 盘器 | **换器** | 叁佐宴 |
| 诗句 | **换一句** | 叁佐宴 |
| 全部 | **全部重来 / 全局随缘** | 包间底栏 / 成宴底栏 |

随机分三层：**全局随机**（重开一桌）→ **单变量随机**（只换一样）→ **兼容随机**（只从与当前选择不冲突的池里抽）。
例：忌虾时不会拿鲜虾当重点；霜天阁不会随机出盛夏冷泡；江月榭不会配京华珐琅锅。

### 多出来的互动

- **拖月亮**：在「其一」时按住月亮左右拖，月位可前后略移，读数会标「（手动）」；点更次即归还常位。
- **点天空**：落点处水面起涟漪。落点压在月上则视为抓月。
- **悬停天时按钮**：匾下诗句先按那种天气预览。
- **走近门**：门自己半开，门内透出暖光，门牌下方浮出「探头」提示。
- **拖动菜序**：改一次序，四位客人的话就换一次。
- **点任意一道菜**：开「配方全卡」——本色配方 + 今夜微调 + 替换（忌口自动换料）。
- **键盘**：走廊左右方向键行走；灯笼可聚焦后用上下键定更。

## 三、搭配规则（不是随机拼的）

- **菜单固定**：六道菜的名字与意象永不变；变的是**配方微调、替换、咸淡**。
  八种口味 × 九种忌口 × 六道菜 → 每道菜一张配方卡，并在「贰上菜」里以**高亮微调框**直接呈现。
- **茶饮**：按 `包间茶池 × 天气冷热偏好 × 时刻 × 口味 × 忌口` 分**前段 / 后段 / 配月饼**三段配。
- **小菜**：从本间小菜池按忌口计分，能凑两样完全不犯忌就不放宽；池子不够时才取「犯忌最少」的两样。
- **盘器**：`包间主调 × 菜品凉热 × 口味轻重` 决定；「换器」只在本间风格内换材质。
- **诗句**：`包间专属诗人 × 心愿诗库 × 天气关键词` 加权抽取，每句带出处。
- **上菜次第**：`清浓相济 / 浓淡次第 / 冷热相续 / 甜意收尾` 四项评分，并触发四种宾客反应。

## 四、全站没有一张图片

月亮、云气、云遮月、微雨、霜降、桂风、桂花粒子、水缸月影、门庭的白墙黛瓦重檐翼角、
走廊的梁、宫灯、灯柱、门槛石与六扇木门、六个包间的内饰、俯视圆桌、18 种盘器材质、
每一道菜的摆盘、成宴的宴图 —— 全部由 **SVG / Canvas / CSS 程序化绘制**。

- `js/art.js` —— Canvas：星空、月与月晕、云气、雨丝、霜雪、桂花瓣、灯下微尘、涟漪、暖光呼吸
- `js/decor.js` —— SVG：六间包间室内意象（月洞门、木格窗、栏杆、江面、冰花、芭蕉、藻井、宫灯……）
- `js/dishes.js` —— SVG：18 种盘器材质（青瓷裂片、水波纹、广彩、景泰蓝、藤编、朱漆描金……）× 6 道菜的摆盘
- `css/style.css` —— 门半开、灯笼摇曳、烛光呼吸、长卷滑走、走廊的梁与宫灯
- `js/audio.js` —— WebAudio 音景：古琴（三角波拨弦 + 弦尾泛音，五声音阶随机成句）、蟋蟀、雨、风、檐角风铃、木门吱呀、铜锣

所以：**不需要任何图片素材**。若日后想加图，`assets/` 目录留空备用。

> 实现注记：不要用 `ctx.filter = 'blur(...)'`。在无头/软件光栅化环境下它会让页面永远画不完（截图与打印会挂住）。
> 云气改用**径向渐变到透明**的叠加来出柔和边缘，真机与无头都稳。

## 六、自检

```powershell
node test/drive.mjs        # 在仿真 DOM 里真走一遍：门庭→天时→大堂→走廊→六间→三幕落座→成宴
node test/selectors.mjs    # 检查 js 里用到的选择器在 index.html 里都存在
```

`drive.mjs` 覆盖：六种天气、五个时刻、六间包间、八种口味、九种忌口、六种心愿、拖拽换序、
四种随机按钮、探头预览、入此间、成宴存图，以及 **6×5＝30 组天时全组合**的渲染。

### 开发用参数

| 参数 | 作用 |
|---|---|
| `?scene=gate\|sky\|hall\|corridor\|room\|feast` | 直接跳到某一幕 |
| `?weather=` | sunny / cloudy / veiled / rain / wind / frost |
| `?time=` | geng1 / midnight / slant / dawn / zenith |
| `?room=` | guiying / wangyue / jiangyue / shuangtian / lingnan / jinghua |
| `?flavor=` | light / standard / strong / sweet / sour / spicy / lessalt / lessoil |
| `?allergies=` | 逗号分隔：shrimp,crab,duck,chicken,nuts,dairy,gluten,alcohol,chenpi |
| `?mood=` | think / reunion / leisure / joy / cold / warm |
| `?step=0\|1` | 选天时的两问 |
| `?stage=0\|1\|2` | 包间的三幕 |
| `?shot=毫秒` | **截图模式**：动画跑够这么久后停住并把标题置为 `READY`，无头浏览器才截得到帧 |
| `?diag=1` | 把页内脚本错误画在画面左下角，便于无头排查 |

示例：

```
?scene=room&room=lingnan&weather=frost&time=slant&flavor=strong&allergies=nuts,dairy&mood=reunion
?scene=feast&room=wangyue&weather=sunny&time=zenith&flavor=light&mood=joy
```

## 七、已知取舍

- 走廊是**横移长卷**，不是真三维透视。深靠梁、宫灯、灯柱、门槛石与地面色差做出层次，
  但凑近看门的厚度仍偏平 —— 若要做真纵深，得换成分层视差或 WebGL，代价大得多。
- 六个包间的内饰是**写意**的：木格窗、月洞门、冰花、芭蕉都由几何形状拼出，
  不是工笔。这是「不用图片」的代价，也是它的趣味所在。
- 「满月当空」时月亮偏大，会稍稍压住天上匾额；这是刻意的（要那种月大得惊人的意思）。
